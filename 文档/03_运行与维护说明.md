# 乡遇一线：运行与维护说明

## 直接打开

双击项目根目录的 `打开作品.html`，或打开 `website/dist/index.html`。所有必要图片、样式和脚本均随项目提供，不依赖 CDN、地图密钥或后端数据库。

建议使用较新的 Microsoft Edge、Chrome、Safari 等浏览器。直接打开本地文件时，浏览器对本机存储和语音的支持可能不同；若保存不可用，可通过导出手账留存。

## 本地服务

电脑已安装 Node.js 时，可双击 `启动本地预览.cmd`。或在 `website` 目录运行：

```powershell
node server.cjs
```

然后访问 `http://127.0.0.1:4173`。关闭终端或按 Ctrl+C 停止服务。服务仅监听本机环回地址，不自动对局域网开放。

## 演示操作

1. 在首页选择“开启乡土旅程”。
2. 尝试三条路线，或选择“调整顺序”勾选、排序。
3. 打开任一点位，阅读故事及观察提示。
4. 回答发现任务，正确后收下主题印记。
5. 在旅行手账写下观察，下载旅行卡或文字手账。
6. 查看行前清单及资料说明。

## 数据保存

路线、收藏、印记、手账和行前清单保存在当前浏览器的 localStorage，键名 `xiangyu-zhuanghe-v1`。它们不上传服务器，也不跨设备同步。清理浏览器数据可能清除记录，使用者可主动导出。

旅行卡为 SVG 文件，可用浏览器打开、打印或使用支持 SVG 的设计工具查看。文字手账及清单为 UTF-8 TXT 文件。

## 修改内容

`website/dist/data.js` 包含四类数据：

- `routes`：路线名称、简介、阅读时长估计、点位顺序。
- `stops`：点位标题、影像、正文、任务、答案、到访提示与来源。
- `checklist`：行前清单。
- 基本标题及版本信息。

编辑文件后刷新页面即可。建议先备份。保持点位 `id` 唯一且不随意更改，路线中的点位 ID 必须存在；问答 `answer` 为从 0 开始的选项索引。若需新增点位，应同步修改“四站”等显示文字以及旅行卡布局。

阅读时长为策划估计，仅指线上内容阅读，不是实测交通或现场体验时间。

## 修改图像与样式

图片在 `website/dist/assets/`，使用有来源、可授权的影像。保留原有相对路径或在数据文件中同步更新。新增影像须更新素材台账。

样式在 `styles.css`，交互在 `app.js`。当前所有资源可离线保留，未引用远程字体。

## 技术检查

在 `website` 目录可运行 `npm run check`，进行 JavaScript 语法检查，无需安装依赖。功能验收记录、浏览器与尺寸说明见 `浏览器验收记录.json`。

## 交付范围与后续接入

本版本提供完整数字体验。线下正式发布前，需要当地管理或经营主体补充并核实地址、交通、开放、预约与收费信息。若后续增加后台、支付或预约，应单独设计身份、数据保护、订单与运营流程。

## 常见情况

**朗读无声：** 浏览器或系统可能没有可用的中文语音，请继续图文阅读；语音能力不影响任务与手账。

**刷新后记录未保留：** 浏览器可能限制本地文件存储或处于不保留数据的模式，请通过本地服务体验并导出记录。

**下载未出现：** 查看浏览器下载列表与文件保存权限；旅行卡默认扩展名为 `.svg`。

**演示页面状态与截图不同：** 截图包含新用户及测试完成状态，当前浏览器会显示自己的记录。
