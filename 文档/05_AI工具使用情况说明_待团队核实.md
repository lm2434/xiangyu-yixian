# 人工智能工具使用情况说明

以下按本次实际制作过程填写，供团队核实后录入赛事系统或官方模板。系统已完整填报的相同内容，不必重复编制。

**是否使用 AI：使用。**

**工具：Codex 中的 AI 助手。** 具体模型或版本如需填写，按本次账户记录核实，不预填未经确认的型号。

## 使用环节

| 环节 | AI 辅助内容 | 后续必须核实的内容 |
|---|---|---|
| 材料整理 | 阅读报告与汇报，整理四主题及来源对应 | 团队确认场景、文化表述、资料权属 |
| 体验策划 | 规划路线、故事结构、观察任务和手账流程 | 学生确认设计选择与地方适用性 |
| 界面与代码 | 生成并修改网页、样式、交互及导出逻辑 | 学生理解实现，复核并承担实际开发工作 |
| 文档 | 辅助生成任务书、说明和演示脚本 | 团队核实完成状态、贡献与赛事材料 |
| 演示视频 | 辅助撰写讲解词、对齐字幕时间；使用 Windows 系统中文语音合成普通话讲解 | 团队复听发音、核对字幕与画面、如实披露合成语音 |
| 检查 | 编写浏览器自动操作，发现并修正图像提取偏差 | 人工检查最终视觉和文化准确性 |

## 主要工作流

用户提供资料 → 文本和图像提取 → 核对场景及来源 → AI 辅助策划与开发 → 浏览器功能检查 → 视觉检查和修正 → 整理项目交付。

## 生成内容与原始材料的区别

文化体验文字、观察任务、问答、页面设计、程序及配套说明使用 AI 辅助形成。事实与照片来自前期资料；没有新增虚构采访、用户评价、游客增长、销售数据、合作或授权。

本次未生成新的乡村照片。图片提取和格式转换属于程序处理。

评审演示配音为系统合成女声，不是真人讲述或受访者原声；逐句字幕与讲解词由 AI 辅助撰写并人工检查时长。团队提交时应按赛事要求披露这一制作方式。

## 学生自主贡献

目前不能替学生预填自主工作量或声称所有核心工作均由学生独立完成。团队应实际阅读、理解、修改和测试作品，按真实参与情况记录：

| 成员代号 | 实际自主完成工作 | 可核验成果 |
|---|---|---|
| 成员 A | 待团队如实填写 | 修改记录、设计说明或实测记录 |
| 成员 B | 待团队如实填写 | 修改记录、设计说明或实测记录 |

如学生尚未参与相关核心工作，不应直接将其申报为已完成的学生自主贡献。

## 数据与版权

处理范围为用户提供的本地文件及制作过程。对前期资料的改编展示权限、人物肖像及第三方图像，由团队进一步确认。网站的个人手账在浏览器本机保存。

实际参赛时，生成合成内容的披露与标识应按官方规范处理；不能因网页未调用大模型 API 而将本次创作填为“未使用 AI”。
